# 复旦研选 · 分类定时选课助手

安装在 **Google Chrome** 中的扩展。在已经登录的复旦研究生选课页面，按 **课程大类 → 课程子类 → 完整“课程名称｜班级”** 自动找课。到达设定的北京时间后，插件先自动刷新选课页、等待页面恢复并重新定位课程，再执行两步选课：**选课 → 确定**。

**版本：0.3.1。** 无需服务器，无需填写账号密码，无需安装编程环境。

> 已在真实网站人工核对课程页面、打开课程确认框，并读取当前公开前端脚本完成分类导航适配。**真实测试没有点击最终“确定”，没有验证实际提交成功。** 扩展逻辑在模拟页面通过自动化测试；首次使用请先预检查和试运行。不能保证名额、毫秒级触发或服务器处理结果。

## 一、下载和安装

1. 下载仓库根目录中的[完整源码与安装包 `fudan-auto-class-v0.3.1.zip`](https://github.com/wenlongli0014-blip/fudan_auto_class/raw/refs/heads/main/fudan-auto-class-v0.3.1.zip)。
2. 将 ZIP **完整解压**，得到 `fudan-auto-class-v0.3.1` 文件夹。源码、测试和 `docs` 文档都包含在包内。
3. 打开 Google Chrome，在地址栏输入 **`chrome://extensions`**。
4. 打开右上角 **开发者模式**。
5. 点击 **加载已解压的扩展程序**。
6. 选择项目里的 **`extension` 子文件夹**。该文件夹直接包含 `manifest.json`。不要选择最外层项目文件夹，也不要选择 ZIP 文件。
7. 点击 Chrome 工具栏的拼图图标，找到 **复旦研选 · 定时选课助手**，点图钉固定。

完成后不要移动或删除安装文件夹。本项目尚未发布到 Chrome 网上应用店；通过上述方式加载即可使用。建议 Chrome 120 或更新版本。

## 二、先登录并连接页面

1. 打开[复旦研究生选课系统](http://yjsxk.fudan.edu.cn/yjsxkapp/sys/xsxkappfudan/xsxkHome/gotoChooseCourse.do)。
2. **自行完成学校统一登录、验证码或二次认证。** 插件不需要也不保存账号密码。
3. 保持选课标签页打开，点击插件图标。插件以普通弹窗或独立窗口打开都可以。
4. 点击 **授权并连接当前选课页**，允许访问 `yjsxk.fudan.edu.cn`。插件会跨 Chrome 窗口查找已打开的选课页，并连接最近使用的那个。
5. 看到“已连接选课标签页”后开始配置。

不能在 GitHub、统一身份认证页或其他网站页面上连接。任务到时由插件发起的刷新会自动重新注入并恢复连接；你在等待期间手动刷新或离开页面仍会使任务暂停。关闭再打开插件弹窗不会断开连接。

## 三、快速找到想选的课程

每张“目标课程”卡片填写以下内容。

### 1. 选择课程大类

| 课程大类 | 继续选择的课程子类 |
| --- | --- |
| 学位公共课 | 政治理论课、第一外国语、专业外语 |
| 学科专业课 | 学位基础课、学位专业课、专业选修课 |
| 公共选修课 | 无需再选子类 |
| 其他可选课程 | 无需再选子类 |

“其他可选课程”对应网站上的同名栏目。这里不包括“已开课程查询”，后者只供查看与资格校验。

### 2. 粘贴完整“课程名称｜班级”

从学校列表中 **“课程名称｜班级”这一列**复制完整文字。必须包含课程名称和末尾的教学班完整编号。例如：

```text
先进微纳加工2026202701PHYS30025.01
```

也允许写成：

```text
先进微纳加工 | 2026202701PHYS30025.01
```

- `先进微纳加工` 是课程名；`2026202701PHYS30025.01` 是完整教学班编号。
- **只填课程名、只填 `PHYS30025`、只填 `.01` 或只填完整编号都不够。**
- 从网页复制带来的换行、空白、全角字符会规范化；英文仍区分大小写。
- `.01`、`.02` 是不同教学班。插件要求课程名和完整班号共同精确匹配。
- 该例用于解释输入格式，不代表推荐你选这门课。请换成你自己的目标。

### 3. 插件如何查询

点击 **查询并检查全部课程** 后，插件会依次：

1. 切换到你选择的课程大类。
2. 如果有子类，再进入对应子类。
3. 将该分类的院系、校区、冲突、是否已满等可清空筛选条件清空。
4. 从完整编号提取课程代码，填入网站原有搜索框，点击网站“查询”。
5. 等待表格更新，用完整“课程名称｜班级”匹配结果。
6. 再核对该行“选课”按钮关联的课程身份。

**只有恰好匹配一行才通过。** 找不到、重复行、错误分类、按钮身份不同或加载超时，都会提示错误并停止。先核对预检查展示的整行信息，再启动任务。

这样不必自己记住院系或手动来回切换分类。预检查会改变学校页面上的分类和查询条件，但**不会点击“选课”或“确定”**。

### 4. 多门课程

点击 **＋ 再添加一门课**，每门课单独设置大类、子类和完整名称。允许不同分类混合。

最多 20 门，同一教学班不能重复添加。按目标列表顺序处理；课程满员时可继续查询后面的目标，再回到未完成目标。最终提交严格串行，当前请求未确认前不会提交下一门课。

## 四、设置时间和运行模式

### 北京时间

开始时间始终按 **北京时间 UTC+08:00** 解释，支持毫秒，例如：

```text
2026-09-09 09:00:00.000
```

不随电脑所在时区改变。界面同时显示当前北京时间，便于核对。

**提前至少一分钟启动，课程多或网络慢时预留更多时间。** 启动后会逐门查询验证并进入等待。到达设定时间时，插件会刷新选课标签页；页面加载完成后重新连接，从第一门待处理课程开始查询，再执行当前模式。若准备阶段已经错过开始时间，任务会暂停。

等待窗口仍从设定时间开始计算，页面刷新和重新查询所花时间也包含在内。刷新速度由学校网站和网络决定，因此实际首次点击一定晚于设定时间；日志会记录“定时触发偏差”和“刷新耗时”。如果刷新后出现登录页、验证码或页面结构异常，任务会暂停，不会盲目点击。

| 设置 | 默认值 | 说明 |
| --- | --- | --- |
| 等待窗口 | 180 秒 | 从计划时刻开始计算，总共允许执行多久；10–1800 秒。 |
| 轮询间隔 | 3 秒 | 每轮处理目标之间的间隔，3–60 秒；页面加载时间另计。 |
| 允许迟到 | 5000 毫秒 | 定时器开始发起刷新超过该偏差时暂停，不刷新、不补抢；100–30000 毫秒。刷新加载耗时不受此项限制，但仍受总等待窗口限制。 |
| 等待学校提交结果 | 90 秒 | 提交后等待学校结果的最长时间；10–180 秒。仍受总等待窗口限制。 |

输入毫秒**不等于保证毫秒精度**。设定时间是“开始刷新页面”的时间，不是点击“选课”或学校服务器收到请求的时间。浏览器定时器、页面刷新、网站加载、系统调度和网络都会产生延迟。请启用系统自动校时。

### 三种模式

| 模式 | 查询分类和课程 | 点击“选课” | 点击最终“确定” |
| --- | --- | --- | --- |
| 只查询演练（默认） | 是 | **否** | **否** |
| 弹窗试运行 | 是 | 是 | **否** |
| 正式选课 | 是 | 是 | 是 |

**只查询演练**：适合第一次核对分类、课程匹配、定时刷新和任务恢复。到时会真实刷新选课页，但不会点击选课或确定；若满员，会继续查询直到窗口结束。

**弹窗试运行**：适合验证真实网站的两步流程。到时只点击目标课“选课”，检查弹窗中的课程名称、完整班号和唯一“确定”按钮，随后自动暂停。**它不会点击确定，你需要手动点击弹窗“取消”。** 一次试运行在第一门成功打开确认框的课程处停止；测试其他课时单独设为目标。

**正式选课**：到时点击“选课”，确认弹窗唯一且课程身份一致后，再自动点击“确定”。提交后只接受本次操作之后出现的学校“选课成功”提示；失败或长时间无结果则暂停，不自动重复提交。

## 五、建议按这个完整流程使用

1. 安装插件，登录学校选课系统，连接当前页面。
2. 添加目标：**课程大类 → 子类（如需要）→ 完整课程名称｜班级**。
3. 点击 **查询并检查全部课程**，核对显示的课程名、班级、教师等整行信息。
4. 第一次先选择 **只查询演练**，设置几分钟之后开始，点击 **启动定时任务**。
5. 演练通过后，改为 **弹窗试运行**，设定新的未来时间，再启动。核对确认框后手动取消。
6. 正式选课前，改为 **正式选课**，填入学校实际开放时间，提前启动。
7. 观察状态从“查询目标中”变成“等待定时”。可以关闭插件弹窗。到时状态会依次显示“正在刷新”“页面加载中”“重新定位中”“执行中”。
8. **保持选课标签页前台、Chrome 窗口可见、电脑唤醒，不要手动操作学校页面。** 插件发起的定时刷新会自动恢复；页面后台化、手动刷新、离开或手动点击/按键会暂停任务。
9. 查看执行日志。最终到学校 **已选课程 / 课表** 核对是否真正选上。

不同分类的后续课程必须切换、查询、等待上一门结果，不能在同一毫秒同时提交。把优先级最高的课放在最前面。

## 六、停止、满员、失败与恢复

- **停止**：插件中的“立即停止”或学校页面右下角浮窗里的“立即停止”。
- 停止阻止后续操作，**无法撤回已经发出的请求**。插件不会自动退课。
- 学校页面手动点击或按键会暂停任务，避免人工操作与自动流程混在一起。打开/关闭插件弹窗不等同于操作学校页面。
- **满员/未开放**：即使“选课”按钮已变成“已满”文字，也可以配置并预检查该课程。任务会重新查询，按钮恢复后才尝试。
- **未提交的普通满员课程**可以继续轮询；**已提交却失败或无明确结果的课程**不会盲目重试。
- 如果出现学校登录框、验证码、资格限制、时间冲突或其他弹窗，先人工处理。插件不会绕过限制。
- 暂停后先人工核对学校已选课程，删除已经完成的目标，修正原因，再设定新的未来时间重新启动。
- 只有插件在计划时间发起的那一次刷新会自动恢复。手动刷新、关闭浏览器或更新扩展后不会自动恢复；配置仍在本机，本次运行状态仅保留在当前浏览器会话。

## 七、日志、更新与卸载

**导出日志**：点击“导出本次日志”保存 JSON，最多保留最近 100 条，包含目标课程、分类、状态和时间。日志不包含密码；分享前仍应检查其中的个人选课信息。

**更新**：先停止任务，下载并解压新版本。在 `chrome://extensions` 中打开旧扩展的“详情”，用“扩展程序路径”确认它实际加载的文件夹；用新版本覆盖该文件夹，或删除旧扩展后重新“加载已解压的扩展程序”。随后点击扩展卡片上的刷新按钮，确认版本号为 0.3.1，再刷新学校页面、重新连接并测试。

**卸载**：在 `chrome://extensions` 中点“移除”。卸载会删除扩展本地配置，已导出的日志文件需自行管理。

## 八、常见问题

| 问题 | 处理办法 |
| --- | --- |
| 点击“授权并连接”没有变化 | 先确认扩展详情显示版本 0.3.1。新版会跨窗口查找选课页，并在插件顶部立即显示“正在查找”“已连接”或具体错误。 |
| 提示“请先打开并登录……” | 在 `yjsxk.fudan.edu.cn` 的已登录选课标签页打开插件；不要在 GitHub 或统一身份认证页连接。 |
| 找不到课程子类 | 检查选课批次是否开放、当前账号是否显示该子类；可能需要更新页面适配。 |
| 完整名称匹配 0 行 | 从“课程名称｜班级”重新完整复制；检查大类和子类、大小写、学期和班号；也可能课程当前不在可选列表。 |
| 匹配超过 1 行 | 网站出现重复结果，插件会拒绝随便选择；先人工检查。 |
| 已满时不立即选 | 会按间隔查询，只有出现可用按钮才点击；不能保证名额。 |
| 弹窗试运行后暂停 | 正常行为，它不会点最终确定；手动取消弹窗后再设置下一次任务。 |
| “页面存在弹窗” | 先手动关闭/取消现有弹窗再重试，避免误确认。 |
| “提交结果未确认” | 可能已成功，也可能学校仍在处理；先查看已选课程，勿马上重复启动。 |
| 后台、睡眠后没有继续 | 前台运行是本版要求；重新连接并启动，不能依靠睡眠电脑定时。 |
| 到点后为什么没有立刻点“选课” | 设定时间是开始自动刷新的时间。插件需等待页面加载、恢复连接并重新查询目标，之后才会点击；具体延迟见日志。 |
| 自动刷新后进入登录页 | 登录态已过期，任务会暂停。重新登录、连接并设置新的未来时间。 |
| “页面结构不符” | 学校前端可能更新，请参考源码包内的 `docs/ADAPTATION.md` 定位变化。 |
| 为什么不同时抢所有课 | 需要按课程确认身份和提交结果，串行处理可避免重复提交、错认弹窗和结果。 |

## 十、隐私与实现边界

扩展使用页面现有登录态，**不读取或存储账号密码、Cookie 或身份令牌**。没有数据上传服务器、统计代码或第三方运行依赖；不直接调用学校隐藏选课接口，而是操作页面原有按钮。学校按钮会按网站正常流程向学校服务器发请求。

权限仅为本机存储、当前标签页、脚本注入及用户主动授予的选课域名访问。详见源码包内的 `docs/PRIVACY.md`。按学校选课规则使用。

实现参考 Chrome 官方的 [Manifest V3](https://developer.chrome.com/docs/extensions/develop/migrate/what-is-mv3)、[内容脚本](https://developer.chrome.com/docs/extensions/develop/concepts/content-scripts)和[后台定时器限制](https://developer.chrome.com/blog/timer-throttling-in-chrome-88)。
